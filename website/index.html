markfmt

A fast, zero-config formatter that rewrites Markdown into one canonical style.

Install

Binaries

  • macOS: arm64 amd64
  • Linux: amd64 arm64
  • Windows: amd64 arm64
  • checksums.txt
  • All releases

Go

Needs Go 1.27 or later.

go install github.com/strangemattersystems/markfmt/cmd/markfmt@latest

Usage

markfmt [-check] [path ...]

markfmt rewrites each file in place. With no path, or the path -, it reads standard input and writes standard output.

# Format files in place
markfmt README.md docs/guide.md

# Read stdin, write stdout
markfmt < draft.md > clean.md

# Fail CI when a file is not formatted
markfmt -check $(git ls-files '*.md')

With -check, markfmt rewrites nothing. It prints each input that is not formatted.

  • 0 All inputs are formatted.
  • 1 With -check, one or more inputs are not formatted.
  • 2 markfmt cannot read, format or write an input.

Container

Mount your files and run the image from ghcr.io. The --user flag keeps your file ownership.

docker run --rm \
  -v "$PWD:/work" -w /work \
  --user "$(id -u):$(id -g)" \
  ghcr.io/strangemattersystems/markfmt README.md

Check files in CI. Pin a release tag in place of latest.

docker run --rm \
  -v "$PWD:/work" -w /work \
  ghcr.io/strangemattersystems/markfmt:latest -check README.md

Format standard input:

docker run --rm -i ghcr.io/strangemattersystems/markfmt < draft.md
